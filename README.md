# learning-c

A simple C expression calculator.

## Build and run

Build the calculator with the default C compiler and warning flags:

```sh
make
```

This creates `build/basic_calculator`. To build and run it:

```sh
make run
```

The default build uses C11 with `-Wall -Wextra -Wpedantic`.

Run the automated calculator tests with:

```sh
make test
```
